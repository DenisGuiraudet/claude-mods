# Claude mods

Mods for Claude Code: plugins of function hooks that change how the app looks.

## La Vallée (`valley`)

Un village de jeu de rôle en pixel art derrière la conversation, dans l'app Desktop. Le modèle, l'effort, le contexte, la limite 5 h, le coût, l'outil en cours, les tâches, les sous-agents et les waves de PR se lisent dans le décor. `/vallee` ouvre la légende.

```
/plugin install valley --marketplace DenisGuiraudet/claude-mods
```

Détails dans [valley/README.md](valley/README.md). Le banc d'essai et les scripts qui génèrent le décor sont dans [lab/valley](lab/valley).
