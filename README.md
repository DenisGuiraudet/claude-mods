# Claude mods

Mods for Claude Code: plugins of function hooks that change how the app looks.

## Session Village (`session-village`)

Un village de jeu de rôle en pixel art derrière la conversation, dans l'app Desktop. Le modèle, l'effort, le contexte, la limite 5 h, le coût, l'outil en cours, les tâches, les sous-agents et les waves de PR se lisent dans le décor. `/village` ouvre la légende, `/village-marges` laisse de la place à gauche et à droite du village.

```
/plugin marketplace add DenisGuiraudet/claude-mods
/plugin install session-village@denis-claude-mods
```

Détails dans [session-village/README.md](session-village/README.md).
